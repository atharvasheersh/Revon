# Reference typography assets

The selected paper layout uses TeX Gyre Termes X by Michael Sharpe, based on
TeX Gyre extensions by B. Jackowski and J. M. Nowacki. Original copyright
notices remain embedded in the font files. The newtx package is published
under LPPL; the underlying TeX Gyre extensions cite the GUST Font License.
See the retained licence texts. Primary package listing:
https://ctan.org/pkg/newtx

The OTF and Type 1 files are the previously used reference-font programs.
TTF files are generated format-conversion outputs used for editable Word
embedding, not an independently designed typeface. Conversion uses fontTools
Cu2QuPen with a 0.25-font-unit curve tolerance, retains glyph metrics, names,
layout tables and copyright notices, and does not claim upstream endorsement.
The conversion script is supplied alongside the renderer. The Revon authors
maintain this publication integration; they do not maintain the upstream fonts.

The fonts and licences are separate from Revon's Apache-2.0 application licence.
