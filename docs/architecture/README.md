# Revon architecture documentation

The Markdown documents in this directory describe the current implementation:

- `CURRENT_MODEL.md` defines the content-addressed trie, incremental commit,
  and hybrid-diff model.
- `SQLITE_PERSISTENCE.md` defines the durable storage and integrity boundary.
- `FINAL_PLATFORM.md` describes how the frontend, API, core, persistence, and
  evaluation layers fit together.

The three PDF companions are generated by:

```powershell
python tools/build_architecture_pdfs.py
```

Rebuild the PDFs whenever the implementation, runtime defaults, paper-profile
threshold, persistence contract, or platform boundary changes. The runtime
default hybrid threshold is 128 operations; the audited paper profile uses a
separately calibrated frozen threshold of 4,096 operations.
