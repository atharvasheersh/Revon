# Chronos research paper

This directory contains the canonical submission artifacts:

- `Chronos_Final_Research_Paper.pdf` - submission-ready seven-page manuscript;
- `Chronos_Final_Research_Paper.docx` - editable source artifact.

The manuscript is generated by `tools/build_final_research_paper.py` from the
reviewed bundles under `evidence/`. Generated drafts and presentation-preparation
material are intentionally excluded from Git.
