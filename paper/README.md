# Revon research paper

This directory contains the editable manuscript and its last exported PDF:

- `Revon_Final_Research_Paper.docx` - revised source covering benchmark-review
  issues 1–21, with remaining scope limits stated in the manuscript.
- `Revon_Final_Research_Paper.pdf` - Microsoft Word export of the current DOCX;
  all 11 A4 pages were rendered at 100 dpi and visually inspected.

The revised DOCX uses the audited primary bundle at
`evidence/paper-corrected-issues13-17-counterbalanced-final-20260923/`, paired
ratio intervals, and separate Windows and WSL2 sensitivity bundles. Issues 18–20
are partly or substantially addressed; the manuscript states the remaining
scope limits. Issue 21 remains partly open: ordered range scans and concurrency
were not measured, and process I/O counters were incomplete. The paper title
describes the implemented index as a Merkle hash trie; Merkle Search Trees are
discussed only as distinct related work.
